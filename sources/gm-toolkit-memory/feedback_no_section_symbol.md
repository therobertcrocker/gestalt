Never use the section symbol (the special "section" glyph used in legal citations) in chat responses, file content, or document headers. Use plain forms instead: "section 3", "sections 4–7", or just "3" / "4–7" when context makes it obvious.

**Why:** Robert finds the symbol visually distracting and dislikes the academic/legal register it imports. Called out twice during the `docs/process/session-modes.md` drafting session.

**How to apply:** When referring to numbered sections in any output (markdown headers, prose, cross-references), spell out "section N". Section headers in markdown should be plain numbers like `## 1 — Purpose`, not `## Section 1` and never with the symbol prefix.
