FacCreds (the SWN currency term) are called **Coin** in this project. Always use "Coin" not "FacCreds".

**Why:** This is the GM's own system, not an SWN product. Custom terminology is intentional.

**How to apply:** Any time currency, income, or faction resources are referenced, use Coin.
